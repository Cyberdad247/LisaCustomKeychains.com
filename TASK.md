# 📜 ANTIGRAVITY TASK PROTOCOL (v49.0)

> "By the order of Sir Lukas: No code shall be written without a map."

## 1. 🔍 THE CONTEXT SCAN (Mandatory)
Before accepting any directive, the Operator must scan the environment:
- [ ] **Read Strategy:** Check `SWARM_REPORT.md` for the current campaign status.
- [ ] **Read Config:** Check `next.config.mjs` and `package.json` to understand the physics of the world.
- [ ] **Identify Dependencies:** List heavily used libraries (e.g., `framer-motion`, `shopify-api`) to avoid reinventing the wheel.

## 2. 🧠 THE THINKING BLOCK (The Hive Mind)
Initiate a `<thinking>` block to consult the Swarm personas:
1.  **Architecture (Syntax):** Is this a Server or Client component? Is it DRY?
2.  **Security (Zenith):** Are inputs sanitized? Are secrets exposed?
3.  **Edge Cases (Octem):** What happens if the network fails? What if data is empty?
4.  **The Plan:** Step-by-step execution path.

## 3. 🔨 ATOMIC EXECUTION
- **One Feature, One Commit:** Do not bundle unrelated changes.
- **Polyglot Compliance:** Ensure TypeScript Strict Mode is respected.
- **Safety**: Use `gravity.write_code` (or standard tool equivalents) for all file operations.

## 4. 📝 THE COMPLETION SIGNAL
A task is NOT done until:
1.  The code is written.
2.  The `VERIFICATION.md` protocol has been executed.
3.  The `PROVENANCE_LEDGER.md` has been updated with the changes.
