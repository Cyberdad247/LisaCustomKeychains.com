## 🛠️ Maintenance Cheatsheet

### "I want to change the price of a keychain..."
> Go to **Shopify Admin** -> **Products**. Click the product -> Scroll to **Pricing**. Update and Save. Changes are instant.

### "I want to add a new keychain photo..."
> Go to **Shopify Admin** -> **Products** -> **Add Product**.
> Title: "Handmade Keychain - [Name]"
> Price: $5.95 (or your choice)
> **Status: Active**

### "I want to change the 'About Me' text..."
> You will need to edit the code file `src/components/AboutSection.tsx`.
> If you are not comfortable with code, ask a developer to update the text inside the `<p>` tags.

### "I want to see my Custom Orders..."
> Go to **Shopify Admin** -> **Orders**. You will see the "Custom Name", "Thread Color", and "Charm" listed under the item properties.
